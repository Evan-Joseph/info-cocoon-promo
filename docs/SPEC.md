## 1. 核心目标与输出规格 (`GOAL & OUTPUT`)

- **GOAL**：让观众从“把一切怪罪给推荐算法”的惯性抱怨，转向看清“毫秒级停留时长商业指标 × 大脑杏仁核身份防御”的双向共谋，并在今晚放下手机与枕边人交换屏幕。
- **OUTPUT**：`1920 × 1080` (`16:9` 横屏主片，兼容 `80% Title-Safe` 中心安全区)，`30 fps`。
- **TIMING DUAL-MODE（双模时序架构）**：
  - **模式 A（`Intrinsic Visual-First` 视觉自然呼吸主模式，默认推荐）**：总长 **`120.0 秒`（`3,600 帧 @ 30fps`）**。每镜时长由其画面生长复杂度与汉字阅读负荷独立决定（在 `5.0s – 7.2s` 之间动态起伏，**严禁连续 3 镜保持相同时长**），内部切镜完全跟随视觉动作与阅读完成（`Cuts follow the motion, not the drums`），仅在 5 个幕际转折点对位参考配乐乐句。
  - **模式 B（`40-Bar Musical Grid` 严格等长音乐网格模式，备选对比）**：总长 **`128.0 秒`（`3,840 帧 @ 30fps`）**，每镜固定 `2 Bars = 6.40s`（`@ 75.0 BPM`）。

## 3. 版面几何与运动定量契约 (`COMPOSITION & MOTION NUMBERS`)

1. **主体占比下限（`Hero Size Floor`）**：每一镜的核心视觉主体（如双手机分屏、《Infotopia》书页、三柱对比图、$10\times 10$ 点阵、劈叉折线图、同心圆环、万赞评论卡）必须占据画幅宽度或高度的 **`45% – 72%`**（绝不允许大面积空旷黑底中间飘一个小图标）。
2. **字号下限（`Typography Scale @ 1920×1080`）**：
   - `L1 屏上主视觉大数/锚字`：`56px – 88px`（`font-weight: 800`，字距 `-0.02em`）；
   - `画内引线直接标注（Direct Callout）`：`28px – 34px`（绝不低于 `28px` = 短边 `2.6%`）；
   - `L2 底部呼吸字幕`：`42px`（位于 `y = 940px` 居中安全区，带高对比半透明底衬，单拍最长不超 `16` 个汉字）。
3. **单一主运动与缓动契约（`One Hero Move & Easing by Role`）**：
   - 每镜仅允许 **1 个主运动（Hero Move）**；次级伴随元素移动幅度为主运动的 `60%`，且延迟 `120ms` 启动；
   - **缓动函数**：元素入场统一用长尾减速 `cubic-bezier(0.16, 1, 0.3, 1)` (`expo.out`)；跨镜相机推拉/变形用 `cubic-bezier(0.65, 0, 0.35, 1)` (`power3.inOut`)；严禁使用 `linear` 匀速运动；
   - **阅读静止铁律**：文字一旦进入读者视线必须完全静止（零漂移、零持续缩放），图表生长完毕后必须保持 **`>= 1.8s–2.5s` 纯静态驻留（Comprehension Hold）**。

## 4. 显式封杀的默认套路清单 (`BANNED BY DEFAULT`)

1. **严禁**深蓝/紫黑渐变虚空背景配漂浮发光粒子或霓虹光晕（Glow/Bloom）；
2. **严禁**在图表旁放置需要眼球来回对照的图例框（Legend）——所有曲线与柱体必须使用**直接引线标注（Direct Leader Line + Label）**；
3. **严禁**连续 3 个镜头保持完全相同的秒数（消除节拍器催眠感）；
4. **严禁**所有元素在同一时间一起淡入上浮（PPT 翻页感）；
5. **严禁**四角放无意义的伪科幻 HUD 十字准星或装饰性英文小字；
6. **严禁**使用方括号纯文本（如 `[切换]`）或乱码字符冒充 UI 控件。
